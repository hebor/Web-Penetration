2. 编辑`upload.php`文件，对上传的文件进行逻辑处理

   $\_FILES是PHP中一个预定义的超全局变量，用于在上传文件时从客户端接收文件，并将其保存到服务器上。它是一个包含上传文件信息的数组，包括文件名、类型、大小、临时文件名等信息。

   - $\_FILES\["表单值"\]\["name"\]：获取上传文件原始名称。\["表单值"\]这个值取决于HTML的"name"元素的值；\["name"\]则是固定格式
   - $\_FILES\["表单值"\]\["type"\]：获取上传文件MIME类型
   - $\_FILES\["表单值"\]\["size"\]：获取上传文件字节单位大小
   - $\_FILES\["表单值"\]\["tmp_name"\]：获取上传的临时副本文件名
   - $\_FILES\["表单值"\]\["error"\]：获取上传时发生的错误代码

   - `move_uploaded_file()`：将上传的文件移动到指定位置的函数

   ```php
   <?php
   $name = $_FILES["file_name"]["name"];    //获取上传文件原始名称
   $type = $_FILES["file_name"]["type"];
   $size = $_FILES["file_name"]["size"];    //默认显示单位为Bytes
   $tmp_name = $_FILES["file_name"]["tmp_name"];
   $error = $_FILES["file_name"]["error"];
   
   //通过打印可以观察到$_FILES对文件上传的判断
   //echo($name."<br />");
   //echo($type."<br />");
   //echo($size."<br />");
   //echo($tmp_name."<br />");
   //echo($error."<br />");
   
   //将上传到临时目录中的文件移动到指定位置
   if (move_uploaded_file($tmp_name, 'upload/'.$name)) {
       echo('<script>alert("文件上传成功")</script>');
   }
   ?>
   ```

   顺利的话，到此为止文件的上传功能已经实现，但在配置的过程中可能还会遇到一些问题，比如Nginx是否启用了上传文件功能、创建的upload目录是否具备可写权限等，我的phpstudy都没有遇见这些问题，因此不做笔录

### 1.2 条件过滤

文件上传功能本身不具备安全防护能力，为了避免攻击者通过上传恶意文件，导致服务器被入侵、数据泄漏等问题，实现文件上传功能后还需要配置条件过滤。PHP的文件上传过滤有3种常见的方式：黑名单过滤、白名单过滤、文件类型过滤

注：所有的功能逻辑的修改都在`upload.php`文件中调整，除非单独声明，否则下文中不会重复提起`upload.html`页面

#### 1.2.1 黑名单过滤

黑名单过滤机制指的是不允许上传特定后缀名的文件，这种方式非常考验开发者的攻防经验，如果开发者没有考虑到所有后缀变形的文件，仍会被攻击者直接绕过黑名单机制，直接上传恶意文件

1. 黑名单示例代码

   ```php
   <?php
   $name = $_FILES["file_name"]["name"];    //获取上传文件原始名称
   $type = $_FILES["file_name"]["type"];
   $size = $_FILES["file_name"]["size"];    //默认显示单位为Bytes
   $tmp_name = $_FILES["file_name"]["tmp_name"];
   $error = $_FILES["file_name"]["error"];
   
   $black_ext = array('php', 'asp', 'jsp', 'aspx');    //定义禁止上传的文件后缀名
   $split_array_result = explode(".", $name);    //explode()函数用于按特定字符分割出上传的文件名称
   $exts = end($split_array_result);    //通过end()函数取数组的最后一个元素，即上传的文件的后缀名
   if (in_array($exts, $black_ext)) {
       echo("非法文件");
   } else {
       if (move_uploaded_file($tmp_name, 'upload/'.$name)) {
           echo('<script>alert("文件上传成功")</script>');
       } else {
           echo('<script>alert("文件上传失败，错误码：'. $error .'")</script>');
       }
   }
   ?>
   ```

#### 1.2.2 白名单过滤

白名单过滤机制与黑名单过滤机制相反，只有明确允许上传的文件后缀名，文件上传才会成功，从机制上来看，白名单就比黑名单更加安全。但是，从运维人员的角度来看，白名单机制的工作量更大

1. 白名单示例代码

   ```php
   <?php
   $name = $_FILES["file_name"]["name"];    //获取上传文件原始名称
   $type = $_FILES["file_name"]["type"];
   $size = $_FILES["file_name"]["size"];    //默认显示单位为Bytes
   $tmp_name = $_FILES["file_name"]["tmp_name"];
   $error = $_FILES["file_name"]["error"];
   
   $white_ext = array('png', 'jpg', 'jpeg', 'gif');    //定义允许上传的文件后缀名
   $split_array_result = explode(".", $name);    //explode()函数用于按特定字符分割出上传的文件名称
   $exts = end($split_array_result);    //通过end()函数取数组的最后一个元素，即上传的文件的后缀名
   if (in_array($exts, $white_ext)) {
       if (move_uploaded_file($tmp_name, 'upload/'.$name)) {
           echo('<script>alert("文件上传成功")</script>');
       } else {
           echo('<script>alert("文件上传失败，错误码：'. $error .'")</script>');
       }    
   } else {
       echo("非法文件");
   }
   ```

#### 1.2.3 MIME过滤机制

```php
<?php
$name = $_FILES["file_name"]["name"];    //获取上传文件原始名称
$type = $_FILES["file_name"]["type"];
$size = $_FILES["file_name"]["size"];    //默认显示单位为Bytes
$tmp_name = $_FILES["file_name"]["tmp_name"];
$error = $_FILES["file_name"]["error"];

$allow_type = array('image/png', 'image/jpg', 'image/jpeg', 'image/gif');
if (in_array($type, $allow_type)) {    //根据文件类型进行判断
    if (move_uploaded_file($tmp_name, 'upload/'.$name)) {
        echo('<script>alert("文件上传成功")</script>');
    } else {
        echo('<script>alert("文件上传失败，错误码：'. $error .'")</script>');
    }    
} else {
    echo("非法文件".$type);    //文件类型非法时输出上传的文件类型
}
?>
```
